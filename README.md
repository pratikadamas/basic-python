A growing collection of scripts, notebooks, and mini-projects I wrote while learning Python from the ground up. This is mostly first-pass practice code, organized by topic so I can easily come back and revise anytime.

---

## 📖 Overview

This repo covers everything from absolute basics (`Hello World`) to OOP, GUI programming with Tkinter, file I/O, data analysis with `pandas`/`numpy`/`scipy`, and a handful of small projects I built along the way. Each file is self-contained — open it, run it, tweak it, that's the idea.

- **⚙️ Python version:** 3.x
- **📄 Format:** Mostly Jupyter notebooks (97%) with some standalone `.py` scripts (3%)
- **💻 IDE used:** PyCharm (`.idea/` folder is just IDE config — safe to ignore)
- **📊 Data files used in notebooks:**
  - `Iris.csv` — classic Iris dataset for ML/data practice
  - `HAM10000_metadata.csv` — skin lesion metadata
  - `season.csv` — small sample for CSV reading exercises
  - `demotxt.txt` — for file-handling demos
